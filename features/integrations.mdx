## Connecting an Integration

Most integrations can be set up in minutes directly from your Google settings. You'll need an account with the third-party service and permission to authorize connections on its behalf.

<Steps>
  <Step title="Go to Settings → Integrations">
    Open **Account Settings** or **Workspace Settings** and select the **Integrations** tab from the left-hand navigation.
  </Step>
  <Step title="Find the service you want to connect">
    Browse the integration directory or use the search bar to locate the app you want to link. Each listing shows a brief description and the types of actions it supports.
  </Step>
  <Step title="Click Connect">
    Select the integration card and click **Connect**. Google will prepare the authorization request for the third-party service.
  </Step>
  <Step title="Authorize the connection in the third-party app">
    You'll be redirected to the external service's authorization page. Log in if prompted, review the requested permissions, and click **Allow** or **Authorize** to complete the handshake.
  </Step>
  <Step title="Configure which events trigger actions">
    Once connected, choose the specific events in Google that should trigger actions in the external service — such as sending a Slack message when a document is shared, or creating a Jira issue when a task is added. Save your configuration to activate the integration.
  </Step>
</Steps>

## Custom Webhooks

If you need to connect Google to an internal tool or a service not listed in the integration directory, custom webhooks give you the flexibility to build exactly what you need. When a specified event occurs in Google, a POST request containing a structured JSON payload is sent to the URL you provide.

To set up a webhook, go to **Settings → Integrations → Webhooks** and enter your endpoint URL along with the events you want to subscribe to. For full details on payload structure, authentication, and retry behavior, see the [Webhooks API documentation](/api/webhooks).
