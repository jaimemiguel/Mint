This guide walks you through everything you need to go from a blank slate to a working API integration with Google. By the end, you'll have a Google account, a valid API key, and a confirmed response from the Google API — giving you a solid foundation to explore the rest of the platform.

<Steps>
  <Step title="Create Your Account">
    Go to [accounts.google.com](https://accounts.google.com) and click **Create account**. Enter your name, choose an email address, and set a strong password. If your organization already uses Google Workspace, ask your admin to invite you instead of creating a personal account.

    Once your account is created, verify your email address to unlock full access to Google's products and developer tools.
  </Step>
  <Step title="Generate an API Key">
    Open the [Google Developer Console](https://console.developers.google.com) and sign in with the account you just created.

    1. Click **Select a project** at the top of the page, then choose **New Project**.
    2. Give your project a name (for example, `my-first-integration`) and click **Create**.
    3. In the left sidebar, navigate to **APIs & Services → Credentials**.
    4. Click **Create Credentials** and select **API key**.
    5. Copy the generated key and store it somewhere safe — you'll use it in the next step.

    <Warning>Keep your API key private. Never commit it to source control or share it publicly. Use environment variables or a secrets manager in production.</Warning>
  </Step>
  <Step title="Make Your First API Call">
    With your API key ready, run the following command in your terminal to fetch your account details from the Google API.

    ```bash
    curl -X GET https://api.google.com/v1/accounts \
      -H "Authorization: Bearer YOUR_API_KEY" \
      -H "Content-Type: application/json"
    ```

    Replace `YOUR_API_KEY` with the key you generated in the previous step. If everything is configured correctly, you'll receive a response like this:

    ```json
    {
      "id": "acc_01H8XYZ",
      "email": "user@example.com",
      "name": "Jane Smith",
      "created_at": "2024-01-15T10:30:00Z",
      "status": "active"
    }
    ```

    A `200 OK` response with your account data confirms that your credentials are working and you're ready to start building.
  </Step>
  <Step title="Explore Features">
    Now that your account and API key are set up, you're ready to explore the broader platform. Browse the [API Reference](/api/introduction) to see what endpoints are available, or dive into specific product documentation to learn how to work with Gmail, Drive, Calendar, and other Google services. Check the guides below to continue your setup.
  </Step>
</Steps>
